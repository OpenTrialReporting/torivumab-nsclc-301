# Pinnacle 21 reports

Reports of record from Pinnacle 21 validation runs. One SDTM + one ADaM report is
kept here as the current pair; each new run replaces it (recorded as a git rename).

Run both standards with `qc/run_p21.sh both [--build]` — see the "Tooling" section
of [`PHASE2-REMEDIATION.md`](PHASE2-REMEDIATION.md).

- **Input XPT:** generated by `programs/export/build_xpt.R` (also runs as the
  finalize step of `programs/adam/00_run_adam.R`) → `xpt/sdtm/`, `xpt/adam/`.
- **Metadata:** the define is emitted per standard, and each run points at its own
  so datasets absent from that run's source folder are not reported missing
  (SD0061): the **SDTM** run uses `define/sdtm/define.xml` (SDTM-only), the
  **ADaM** run uses the combined `define/define.xml` (it loads SDTM + ADaM
  together for traceability).
- **Engines:** SDTM-IG 3.4 (FDA), ADaM-IG 1.3 (FDA); engine/config 2508.1,
  CDISC CT 2026-03-27.

**Current validated state: SDTM 10,891 (9 rules) / ADaM 10,890 (8 rules)** — of
which 10,873 is the accepted SD0007 DA standard-units warning. Every remaining
finding is a documented accepted limitation.

P21 finding IDs and their disposition (fixed vs. accepted synthetic-data
limitation) are tracked in [`PHASE2-REMEDIATION.md`](PHASE2-REMEDIATION.md),
alongside the raw reports (Excel) here. Accepted limitations that have a natural
home are also annotated in `define.xml` itself via `def:CommentDef`.
