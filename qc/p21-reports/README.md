# Pinnacle 21 reports

Reports of record from Pinnacle 21 validation runs. Drop each run in a dated
subfolder, e.g. `qc/p21-reports/2026-07-18/`.

- **Input XPT:** generated by `programs/export/build_xpt.R` (also runs as the
  finalize step of `programs/adam/00_run_adam.R`) → `xpt/sdtm/`, `xpt/adam/`.
- **Metadata:** `define/define.xml`.
- **Engines:** SDTM-IG 3.4, ADaM-IG 1.3.

Accepted __ P21 finding IDs and their disposition (fix vs. accepted synthetic-data
limitation) are tracked here alongside the raw report (Excel/CSV).
